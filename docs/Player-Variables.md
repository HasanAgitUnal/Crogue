Player variables are under `cr.player` table.

### Updating HP

Use these functions to get or set hp:
* `cr.player.get_hp()`
* `cr.player.set_hp(value)`

### Updating Level

Use these functions to get or set level:
* `cr.player.get_level()`
* `cr.player.set_level(value)`

### Inventory

Inventory is accessed from `cr.player.inventory`. Its a list of [shared cards](./Shared-Types).

See [Game Status & Containers](./Game-Status-&-Containers.md) to understant containers.
